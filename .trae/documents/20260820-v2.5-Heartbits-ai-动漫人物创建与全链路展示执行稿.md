## 1. 背景

v2.3 起首页具备 All / Female / Male / Anime 四个分类，Anime 分类仅有种子人物、不可创建。本版本补齐动漫人物的创建能力，并统一全站人物展示规则：

1. **创建能力**：创建人物入口新增类型选择，动漫人物走「基本信息 → 提示词生图 → 人物设定」三步流程。
2. **展示规则统一**：年龄、国家一律改为「数据有就展示、没有就不展示」，不再按真人/动漫一刀切，也不再编造数据。
3. **链路兼容**：动漫人物在首页、分类页、对话、Discover、收藏、创建记录等处正常展示，无字段缺失导致的空白或错乱。

## 4. 核心概念与数据

### 4.1 人物类型 kind

- 取值：`female` / `male` / `anime`；归一化规则：非 `male`、非 `anime` 一律视为 `female`。
- 种子人物：真人 16 名（含年龄、无国家字段）、动漫 30 名（其中 Aki 等 6 名带年龄数据，其余 24 名年龄为空）。
- 创建人物：id 以 `u_` 前缀；动漫创建人物默认**无年龄数据**（age 为 null）、无国家数据。
- 创建人物字段：`name`、`bio`（由人物设定描述生成的简介，用于卡片展示）、`starter`（取「对话的第一句话」，作为新会话开场白）、`avatarUrl` / `heroUrl`（形象图）、`tags`（已选性格）、`kind`、`isPublic`、`ownerKey`。

### 4.2 创建草稿（characterCreations）

- 草稿 id 以 `cr_` 前缀；字段含 `kind`、`status`、`appearance`、`portraitUrl`、`characterIdea`、`texts`、`isPublic`、`isPublicTouched`、`characterId`、`ownerKey`。
- 状态机：
  - 人类：`gender → appearance → portrait → description → 完成（characterId 非空）`
  - 动漫：`anime-basic → anime-portrait → description → 完成（characterId 非空）`
- 同一时间仅保留一个未完成草稿；点击「重新创建」或选择新类型时清除旧未完成草稿。
- 草稿与创建记录均持久化（localStorage，键 `ai-dialog-home`），刷新/重进可续建。

### 4.3 公开 / 私密

- `isPublic`：公开人物对所有用户可见，私密仅创建者本人可见（`getAllCharacters` 按 `ownerKey` 过滤）。
- 动漫草稿默认 `isPublic = true`（公开人物开关默认打开，R7）；真人草稿默认 false。
- `isPublicTouched`：用户手动拨动开关后置 true，此后任何情况下以用户选择为准，默认值不再覆盖。

### 4.4 钻石消耗（沿用既有规则，本版本不新增计费项）

| 行为 | 消耗 |
| --- | --- |
| 首个创建人物的生图 | 免费 |
| 后续人物生图 / 重新生图 | 2 钻石 |
| 对话中 Request Image | 1 钻石 |
| 对话中 Request Video | 2 钻石 |

## 5. 逐页规格

### 5.1 创建页 `/create`

**类型选择弹窗（R1）**

- 触发：点击「创建人物」。
- 内容：两张类型卡——
  - 人类：外貌设定 → 形象图 → 人物设定，创建真人风格人物。
  - 动漫人：基本信息 → 提示词生图 → 人物设定，创建动漫风格人物。
- 交互：点某类型即创建对应 kind 的草稿并进入该流程第一步；「×」关闭不创建。

**草稿横幅**

- 存在未完成草稿时，页面顶部展示「继续上次草稿 / 重新创建」。
- 「继续上次草稿」恢复该草稿到其中断的步骤；「重新创建」清除未完成草稿并打开类型选择弹窗。

**动漫第一步 · 基本信息**

- 姓名（必填）：输入框 + 5 个推荐名按钮（Aki / Hana / Ren / Mio / Yuki），点击推荐名直接填入。
- 性格（最多 3 个）：
  - 新草稿进入时**默认随机预选 1 个**性格并持久化；
  - **必选**：未选任何性格点击「下一步」时 toast「请至少选择一个性格」，不进入下一步；
  - 已选性格以可删除 chip 展示（「删除性格 XX」），候选区对应按钮置灰；
  - 「换一换」刷新一组候选性格。
- 本步骤**不含语言选择**（R10）。
- 「下一步」校验：姓名非空 + 性格至少 1 个 → 进入 `anime-portrait`。

**动漫第二步 · 形象确认**

- 仅保留**提示词生成**方式，**不提供上传本地照片**（R10）。
- 左侧：提示词输入框（500 字、带字数计数），示例占位「描述你想要的动漫形象，例如：silver-blue hair, light jacket, soft sci-fi atmosphere」。
- 生图按钮文案与计费：已有形象时为「重新生成图片（2 钻石）」；无形象时首个创建人物为「首次生成免费」，否则「生成图片（2 钻石）」；提示词为空时按钮禁用。
- 钻石不足时沿用现有钻石引导弹窗。
- 右侧「形象展示」卡：生成后展示竖版形象图；未生成时占位文案「点击“生成图片”后展示」。
- 「上一步」回基本信息；「下一步」在未生成形象时禁用，生成后进入 `description`。

**动漫第三步 · 人物设定**

- 左侧设定描述输入框（500 字、带计数），占位引导从「人物关系 / 对话场景 / 第一句话 / 消息案例」四方面描述。
- **必填生成（R2 关键规则）**：动漫人物设定描述为空时——
  - 「生成 / 重新生成」按钮禁用，并展示提示「动漫人物需先填写设定描述，才能生成人物设定。」；
  - 处理函数兜底校验：空内容触发 toast「请先填写你希望这个人是什么样的」，不生成。
  - 真人流程不受此限制（保持原行为）。
- 生成后右侧展示四张设定卡：人物与用户关系 / 对话场景 / 对话的第一句话 / 消息案例。
- 「公开人物」开关：动漫默认打开（R7）；用户手动拨动后以用户选择为准。
- 「保存并生成人物」：设定未生成时禁用；成功后写入 `createdCharacters`（kind 为 anime、age 为 null、头像/形象图为生成的形象图、开场白取「对话的第一句话」、性格取已选性格），进入完成态并 toast「人物已创建」。

**完成页**

- 展示「人物已完成」徽章、人物名、性格 chips、形象图、「开始对话」按钮。
- 年龄 / 国家卡片**按数据展示**：有年龄数据才显示年龄卡，有国家数据才显示国家卡；动漫创建人物默认两者皆无，故不显示（R5）。
- 不展示语言、类型卡片（R10）。

**创建记录列表**

- 每条记录卡展示：形象图、状态（已完成 / 进行中）、姓名、副标题。
- 副标题规则：动漫为「动漫」；真人为「国家 · 性别」（缺失项按原规则省略）。
- 点击记录进入 `/create/record/:id`。

### 5.2 创建记录详情 `/create/record/:id`

- 展示：形象图（加载失败回退默认图）、姓名、公开/私密标签、性格 chips、人物设定四项（人物与用户关系 / 对话场景 / 对话的第一句话 / 消息案例，空值显示「—」）。
- 动漫记录**不展示语言标签**（R10）。
- 属主操作：「开始对话」（打开该人物会话并跳转 `/chat/:id`）、「删除角色」（二次确认；删除后该角色、其创造记录与相关对话一并移除）。
- 记录不存在或未完成时展示兜底文案与「返回创建页」按钮。

### 5.3 首页与分类页（本版本调整专项）

页面结构沿用 v2.3（顶部分类 Tab All / Female / Male / Anime；品类页为 Banner + 人物网格 + 品类 FAQ + SEO 文案块 + 页脚）。本版本对首页/分类页的调整共 4 项：

**调整 1：创建人物优先展示（R4）**

- 范围：首页 All 与 Female / Male / Anime 各分类页的 Characters 区。
- 规则：创建人物（`u_` 前缀，含真人与动漫）整体排在种子人物之前，再套用原有 24 卡上限。
- All 页混排规则：优先排序后按 female / male / anime 交替混排。
- 目的：解决创建人物被 24 卡上限截断、创建后在首页/分类页看不到的问题；保证用户创建的人物一定首屏可见。

**调整 2：卡片年龄改为数据驱动（R5/R6）**

- 卡片右下角年龄「有值才展示、无值不展示」，不再按真人/动漫一刀切。
- 实际效果：真人种子照常展示年龄；动漫种子中带年龄数据的 6 名（如 Aki 展示 19）展示年龄，其余无年龄数据的动漫人物与创建人物不展示。

**调整 3：Anime 分类页 FAQ 文案同步新规则**

- 旧文案「Why don’t anime cards show age?（动漫卡为什么不展示年龄）」废弃。
- 新文案「When do anime cards show age? — Age is shown only when the character has age data. Characters without age data keep a clean, stylized card.」

**调整 4：卡片交互与模块保持不变**

- 卡片 hover 浮层 + Chat 入口、点击进对话等交互不变；首页 Quick Access、短剧模块、Banner 等模块不变。
- 明确不调整项（本期评估后维持现状）：动漫卡片 hover 视频仍复用现有真人 hover 素材；对话内 Request Image/Video 仍返回现有素材；Profile 兜底图仍为现有默认图。

### 5.4 对话页 `/chat/:id`

- 头部信息：人物名下方年龄行**有值才展示**（R5）。
- Profile 区块：
  - Country 块展示规则：**真人人物的国家为必有信息（数据库必返回），故真人一律展示 Country 块；动漫人物按数据库返回判断——返回了国家信息就展示，没返回就不展示**。前端统一按「国家字段是否有返回」决定是否渲染该块，不再编造国家数据（R5）。
  - Personality 块：保留原有展示。
  - 动漫人物**不展示语言标签**。
- 短剧标签：人物无短剧数据时（动漫人物均无），Profile 中 Micro-Dramas 标签自动隐藏。
- 开场白：新会话首条消息取人物 `starter`（动漫创建人物取创建时「对话的第一句话」）。
- 登录拦截、收藏、分享、Request Image/Video 等沿用既有规则。

### 5.5 Discover `/feed`

- 信息流新增 1 条**动漫视频条目**（R8）：复用现有 `anime-feed-01` 视频与封面素材，不新增素材。
- 该条目人物信息：头像/封面使用动漫素材，年龄隐藏，用户名 `@aki`，Chat 入口进入动漫人物 Aki 的会话。
- 其余信息流条目、点赞/评论/关注/解锁/分享等逻辑不变。

### 5.6 收藏 `/favorites`

- Characters / Created 标签使用统一人物卡片，年龄展示遵循数据驱动规则（R5）。
- 创建的动漫人物可被收藏、可发起对话，行为与真人一致。

## 6. 关键用户流程

### 6.1 动漫人物创建全流程

1. `/create` → 「创建人物」→ 弹窗选「动漫人」→ 创建草稿，进入基本信息。
2. 基本信息：姓名（必填）+ 性格（默认预选 1 个、必选）→「下一步」。
3. 形象确认：填写提示词 →「生成图片」（首人物免费，否则 2 钻石）→ 形象展示 →「下一步」。
4. 人物设定：填写设定描述（必填）→「生成」四段设定 → 确认公开开关（默认开）→「保存并生成人物」。
5. 完成页：展示人物与「开始对话」；创建记录列表出现该记录（副标题「动漫」）。
6. 任一步「上一步」可回退，数据保留在草稿中；中途退出后可经草稿横幅续建。

### 6.2 草稿续建

- 存在未完成草稿时，`/create` 展示「继续上次草稿 / 重新创建」。
- 续建恢复到中断步骤，已填姓名/性格/形象/设定/公开开关均保留。

### 6.3 可见性

- 公开人物：所有用户的首页/分类页可见。
- 私密人物：仅创建者本人可见（含其首页/分类页/收藏/对话）。

## 7. 展示规则矩阵（R5/R6/R10）

| 字段 | 位置 | 规则 |
| --- | --- | --- |
| 年龄 | 人物卡片、对话页头部、Discover 人物信息、创建结果页 | 有值展示，无值不展示；不按真人/动漫区分 |
| 国家 | 对话页 Profile、创建结果页 | 真人必有国家（必展示）；动漫按数据库返回判断，有返回展示、无返回隐藏；前端按字段返回与否渲染；不编造 |
| 语言 | 创建第一步、创建结果页、记录列表/详情、对话页 | 本版本不选择、不展示 |
| 类型（动漫） | 创建结果页、记录列表 | 结果页不展示类型卡；记录列表副标题为「动漫」 |

## 8. Mock 与真实边界说明

- 人物数据、形象生图（text_to_image 远程图）、对话回复均为 Demo 本地 mock；钻石、订阅为本地 mock 计费。
- 本版本动漫形象仅提示词生图，无文件上传与存储。
- 种子动漫人物中 6 名带年龄数据属 mock 数据设定，用于验证「有数据就展示」规则。

## 9. 真实产品版注意

- 人物实体、形象生成、公开/私密可见性需服务端化并账号隔离；`isPublicTouched` 类「用户已手动选择」标记需随账号持久化。
- 年龄 / 国家遵循「有就展示」，服务端按字段缺省返回即可，前端无需特判类型。
- 语言字段前端已移除，服务端无需为该版本预留。
- 创建人物优先展示为前端排序策略，真实产品可改为服务端推荐位。

## 10. 验收标准

1. 创建入口弹窗可选人类/动漫人，选择后进入对应流程；动漫流程为三步且无语言选择、无上传本地照片。
2. 动漫基本信息：新草稿默认预选 1 个性格；性格为空时「下一步」被拦截并提示。
3. 动漫形象确认：提示词为空不能生图；首人物生图免费、其余生图/重新生图扣 2 钻石；未生成形象不能进入下一步。
4. 动漫人物设定：描述为空时「生成/重新生成」禁用且有提示文案；填写后可生成四段设定；未生成设定不能保存。
5. 公开人物开关动漫默认打开；手动关闭后重进仍保持关闭。
6. 完成页与记录详情不展示语言/类型；年龄/国家卡片按数据展示。
7. 创建的动漫人物在 `/anime` 与首页 All 优先可见，不被 24 卡截断。
8. 卡片/对话/Discover 年龄有值才展示（Aki 展示 19，无年龄数据者不展示）。
9. 对话页 Profile：真人人物一律展示 Country 块；动漫人物仅在数据库返回国家信息时展示 Country 块，未返回时该块隐藏；任何情况下不编造国家数据。
10. Discover 含 1 条动漫视频条目，Chat 进入 Aki 会话；动漫对话页无 Micro-Dramas 标签。
11. 真人创建与展示流程无回归（年龄/国家有数据时正常展示，设定可空生成）。
